Nube

Google Drive

Dos acciones separadas (nunca se mezclan solas): Guardar sube esta PC a Drive; Cargar baja Drive y reemplaza esta PC (con respaldo previo).

Una sola vez: creá un cliente OAuth “Escritorio” en Google Cloud, activá Drive API y pegá acá Client ID y Secret. Guía en README (sección Drive).

Drive no configurado.

«Subir cambios solos» solo hace Guardar en segundo plano. Nunca baja ni pisa esta PC. En una PC nueva o vacía: primero Cargar, no Guardar.
